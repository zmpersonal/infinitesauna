Terminology guide

Low, ultra-low and near-zero EMF labels.

These phrases appear frequently in infrared-sauna marketing, but a label by itself does not tell you the test method, measurement location or operating condition.

How Infinite Sauna handles the labels

The database records the manufacturer or retailer terminology—such as “Low,” “Ultra Low” or “Near Zero”—when it is explicitly stated. It does not convert those marketing categories into a universal numerical ranking.

Why numerical comparisons need context

An EMF number can depend on where the meter is positioned, which component is being measured, the distance from the source and the measurement protocol. Two brands can therefore publish numbers that are not directly comparable unless the methodology is also comparable.

Practical database rule: a blank EMF field means “not verified from the current sources,” not “high EMF.”

Use model documentation for technical claims

If EMF performance is an important purchasing criterion, review the manufacturer’s current test documentation for the exact model and ask how measurements were taken. Infinite Sauna’s role is to make the stated terminology searchable and comparable, not to certify the underlying measurements.
