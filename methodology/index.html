Transparency

How the database is built.

Infinite Sauna is designed to make specifications easier to compare without pretending every field is equally available or equally reliable.

Primary catalog source

The automated updater starts with the public sauna catalog at InHouse Wellness. It records product identity, brand, current listed price, reference price when available, model/SKU, image and product URL. The updater also parses product-page text for technical specifications.

Commercial disclosure: InHouse Wellness is intentionally the featured retail option throughout Infinite Sauna. The database is still designed to preserve source transparency: manufacturer pages can supplement missing technical fields, and the site labels fields as “Not verified” rather than inventing a value.

Manufacturer enrichment

Some technical specifications are easier to verify on the manufacturer’s own product page. A source list in data/manufacturer_sources.csv lets the updater pull missing fields from official pages. Manufacturer data fills gaps; it does not silently replace a populated field during the same refresh.

Starter examples include Golden Designs for the Arosa barrel sauna and SaunaLife for the E8G barrel sauna. New sources can be added without changing the site code.

Fields we normalize

The schema currently supports brand, model, title, price, reference price, sauna type, placement, capacity, voltage, amperage, plug type, EMF terminology, infrared spectrum, red-light integration, infrared wattage, traditional heater, heater output, maximum temperature, exterior dimensions, interior dimensions, wood/materials, product weight and warranty.

What “Not verified” means

It means the current automated sources did not expose that field in a form the parser could identify reliably. It does not mean the sauna lacks the feature. This distinction matters especially for EMF terminology, red-light systems, warranty details and electrical specifications.

Update frequency

A GitHub Actions workflow is configured to refresh the database weekly and can also be run manually. The static site is regenerated after every successful refresh, including model pages, brand pages, curated comparison pages, CSV output and the XML sitemap.

Corrections

Specifications can change, and manufacturers sometimes revise products without changing a consumer-facing model name. Buyers should verify critical installation details—especially voltage, amperage, plug/receptacle requirements, heater clearances and outdoor siting—with the current manufacturer documentation and a qualified electrician where applicable.
